開放回饋主題

原始題目：如果後續只能增加一項教材或協助，你最希望是什麼？

  • 希望提供更多範例、FAQ、公文草稿範本與簡報素材
  • 希望補上內部網站／內網資料、動態網頁、多層網頁來源限制的情境教學
  • 對 Copilot Studio、Microsoft Foundry、多 Agent 串接、模型選配與開源模型適用性有興趣
  • 有部門情境需求：圖面審查、法規條文查詢、電力系統專業研究應用
  • 有人建議定期在訓練所開實體課，降低線上課被工作中斷的問題

後續建議

建議後續行動

  1. 1. 補一份治理速查
    用一頁說清楚 Copilot Chat、Agent Builder、Copilot Studio、資料來源、授權、權限與用量限制
  2. 2. 做「答案核對」練習包
    提供測試題、錯誤樣態、引用檢查與修訂範例，對應目前最低的信心項目
  3. 3. 擴充台電情境範本
    優先補公文草稿、會議紀錄、SOP／法規查詢與新人 FAQ，並加入內網資料可用性說明
  4. 4. 規劃進階場
    聚焦 Copilot Studio／Foundry、多 Agent 串接、部門資料整理與高風險情境治理
